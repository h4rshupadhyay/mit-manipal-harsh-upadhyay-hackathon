# Pre-register and chronologically validate project conventions

The event window, Reference Basket construction, analogue matching and back-off rules, confidence threshold, economic materiality floor, and other project-specific conventions will be selected only on nested chronological development splits, frozen, and then evaluated once on an untouched final period. The system will distinguish established methods, requirement-driven contracts, and project judgment in its documentation; a hypothetical scenario or demo policy will never be presented as empirically optimal.
