# Validate with historical backtests and case studies

The project will validate Risk Signals with temporally out-of-sample historical backtests and explainable event drill-downs rather than rely only on a manually labeled classification benchmark. Deep severity calibration will focus on four well-supported event families, while thin-history classes will use conservative priors and visibly capped confidence. The global evaluation will include an RBI monetary-policy episode and an Indian credit/default episode so the portfolio's India exposure is tested rather than merely displayed.
